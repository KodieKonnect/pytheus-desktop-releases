# Pytheus™ desktop

Installers for the Pytheus desktop app on macOS and Windows. This repository holds release binaries and update manifests only. The app's source lives in a private repository.

## Download

| Platform | Installer |
| --- | --- |
| macOS 12 or later (Apple silicon and Intel) | [Pytheus.dmg](https://github.com/KodieKonnect/pytheus-desktop-releases/releases/latest/download/Pytheus.dmg) |
| Windows 10 or later (64-bit) | [Pytheus-Setup.exe](https://github.com/KodieKonnect/pytheus-desktop-releases/releases/latest/download/Pytheus-Setup.exe) |

These links always point at the newest release. Installed copies update themselves in the background and offer to restart when an update is ready.

The macOS app is signed with an Apple Developer ID and notarized by Apple. Windows builds are not code-signed yet, so Windows may ask you to confirm before the installer runs.

Sign in with your Pytheus account. Single sign-on opens in your default browser and returns you to the app.
